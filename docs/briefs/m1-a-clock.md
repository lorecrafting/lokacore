## M1-A: authority elapsed contract and pure entry

Existing `run_job`, `time.advance`, ordered due drain and changed-row storage remain. No new delta op, scheduler, Effect or world snapshot.

**Chosen contract.** Add a cartridge-declared `real_elapsed` profile/rate using checked integer milliseconds and fractional remainder; sampler declares 50 logical seconds/real second. Legacy releases without the profile retain frozen `play_time` wait/duration/calendar/resource behavior. New elapsed releases reject nonzero recipe durations and cannot expose Wait directly, through cartridge actions or aliases. Elapsed actions never synthesize duration charges. Future timed occupation requires an exercised consumer and new brief.

Register one authority-only elapsed command owned by schedule, carrying explicit logical target plus actor/world identity for existing causation. Use a distinct IdSource command domain; proposed canonical identity is `["loka-elapsed-command-v1", run_id, world_context_id, from, target]`. The narrow authority entry requires captured `expected_run_id` and matches the current durable save run **before receipt lookup**; within a matched run preserve existing receipt-before-freshness ordering. A stale old run returns an existing typed refusal without a receipt or state change; freeze its precise kind in the implementation contract. The semantic identity is the durable save run, not authority placement/session. Do not add `World.run_id` or change portable whole-state hashes. Freeze the final tuple/known-answer bytes under the numeric profile before code; an actual collision or missing run identity is a scope trigger, not permission to invent another ID scheme. Normal invocation/ActionSet/cartridge paths cannot construct or admit it. A narrow trusted kernel/authority entry routes it through existing identity validation, capability ownership, budgets, proposal adoption and receipts. Never expose a general admission-bypass flag. Nil/wrong-world/wrong-actor rejection remains. Modal scenes still offer only player Continue; elapsed delivery works independently of that player admission.

The pure rule emits the existing `time.advance`, no wall-clock read, unrelated event or RNG draw. One raw interval is bounded by the existing advance contract. M1-A does not claim that one long leap handles newly scheduled recurrence: M1-B segments at earliest due boundaries. Re-read job generation when the first actual cancellation/rescheduling producer arrives; do not falsely mark that carry fixed merely by registering time.
