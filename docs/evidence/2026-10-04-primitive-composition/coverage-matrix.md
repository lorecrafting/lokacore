# Primitive composition coverage matrix

Read-only architecture advice at merged `6d9712ef2b0ea12be537e4ef4c826a6d04e155af`. No tests, builds, code approvals or implementation are claimed. Private formal briefs and source-only `docs/LATER-MECHANICS.md` are plans, never merged truth. Pending PR136 policy is identified where used. `mechanics/`, `runtime/`, `foundation/`, `commands/`, `view/` evidence names mean `kernel/ts/src/` unless explicitly qualified. `archive/spec/06` means `docs/archive/spec/06-quests-dialogue-actions-scripting.md`.

Every row inherits: pure deterministic kernel; trusted invocation and closed authoring/load contracts; explicit typed target/scopes; preconditions and writer-group conflict semantics; one atomic proposal and changed-row host transaction; receipt replay without re-execution; precharged bounded new traversal/delivery; rollback of state/RNG/events on fault; cartridge-owned world values. These common contracts are not repeated as new tests per mechanic. Row-specific invariants below identify the additional composition obligation.

Legend: NEW means a missing reusable semantic contract warranted by the named consumer, not an instruction to create a package, framework or generic registry. Existing schema versions/API gates are selected when the brief is pinned. New RPG code stays TypeScript-only until server consumption; foundation algebra changes need both twins and independent fixture/differential evidence. All first consumers need focused automated/Simulator-first proof; owner physical-device/manual acceptance is deferred to its later gate.

Coverage: 37 registered feature-map capabilities (22 installed subsets, 15 not yet), every M1–M23 group, 29 C2/C3 mechanic candidates, ten authored content batches, five continuity/product candidates and eight foundation/host responsibility rows. Later candidate IDs count C2-M14A and C2-M14B separately.
