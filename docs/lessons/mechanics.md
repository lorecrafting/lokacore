# Mechanics lessons

Verified lessons from mechanics changes. The rules live in [building mechanics by composition](../system/architecture.md#building-mechanics-by-composition) and [mechanics](../system/mechanics.md).

- Check every committed intermediate mechanic state with the real save loader and the later delivery that consumes it. In M6-A, a scheduled opponent departure between Attack and its due round committed successfully, but cold reopen rejected the save; [PR #168's review and fix](https://github.com/lorecrafting/lokacore/blob/f8513671ea7dd84d681876b2e36850129a4b0564/docs/reviews/2026-10-05-m6-a-first-live-fight-review.md) and the [SQLite regression](https://github.com/lorecrafting/lokacore/blob/f8513671ea7dd84d681876b2e36850129a4b0564/docs/evidence/2026-10-04-m6-a-first-live-fight/README.md#review-round-1-lawful-scheduled-departure) cover reopen, COMMIT reconciliation and harmless due-time completion.
- Queries used while composing one command share that command's budget across candidate evaluations. Giving each random-Flee candidate a fresh policy-query counter let total work exceed the command limit; [the controlled regression](../../kernel/ts/test/combat_flee.test.ts) exhausts `query_steps` across candidates and requires an atomic fault. PR #168 records the corrected accounting and red control.
- An offered action must pass its exact keyed target and input admission before the view calls a mechanic's pure transition. In B4, a narrowed authored light alias appeared usable although execution refused it; the [independent review and fix](https://github.com/lorecrafting/lokacore/blob/f8513671ea7dd84d681876b2e36850129a4b0564/docs/reviews/2026-10-05-b4-light-primary-review.md) now reuse ordinary admission. An authored action key is not its resolved command: project by command while preserving the key used for invocation, and include a loaded alias whose key differs from the command in the view-to-invocation check. When a later mechanic duplicates eligibility ordering between its rule and GameView, move that read-only check into the mechanic's existing shared module and prove the concrete break with a red control. Keep Book placement and wording separate from eligibility; do not run a full decision to render actions.
- Jobs due at the same logical time run in either order. A fatal combat job and a population job sharing a due boundary targeted conflicting plans; test both orders with literal expected states ([C3 plan review](https://github.com/lorecrafting/lokacore/blob/f8513671ea7dd84d681876b2e36850129a4b0564/docs/reviews/2026-10-05-c3-living-hounds-plan-review.md)).
