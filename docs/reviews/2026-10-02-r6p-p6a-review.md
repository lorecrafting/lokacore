## Findings

- **F-1 should-fix** — mobile/authority/local-story/observe.test.ts:150. No test sends a rejected
  invocation with the clock set. Mutants "no record when `resolve` returns a rejection" and "no record
  when the saved decision is `rejected`" (authority.ts:212) both leave the suite green. Failure
  scenario: a later edit times only the `step` branch, or filters `rejected`. P6b's phone timing then
  silently drops every rejected decision, and the envelope §5 percentiles leave out a class that the

  so that `expected` has three rows.
