## Findings

### Must-fix 1: stale sheet writes go through the stale guard

`kernel/ts/play/mapedit.ts:292`, `mobile/app/author/build/form.tsx:48,136,152-175`.
- `change(file, ops)` builds its ops from the sheet's cached doc. `s.change(file, () => ops)` ignores the fresh doc but sends the fresh sha as `was`, so `fresh()` never refuses. Every other mapedit gesture builds its ops from the fresh doc.
- Repro, list: statuses `allows: [a,b,c]` open, source changed to `[a,b,c,d]`, Move up on item 2. Posted `{"path":["allows"],"value":["a","c","b"]}`, so `d` is lost.
- Repro, map: facts open, key `gate {initial:true}` added behind the sheet, Add `gate`. Posted `{"path":["facts","gate"],"value":{}}`, which overwrites it. "An existing key is never overwritten" holds only against the cache.
- Realistic trigger: a double-tapped Remove. `busy` clears after the first gesture, but the sheet draws the old list until /story, /source and /schema return. The second tap deletes index i of the closed-up list, so the next element is lost too.
- Fix: build the ops from the fresh doc inside the `s.change` callback, or send the sha the sheet read as `was`.

### Should-fix 1: book `generic` is accepted on panel-bespoke rows

Gate exit 0, and both rows pass in `generic.test.ts`. The row loop (`generic.test.ts:136-158`) checks only `ops[*].path[0]`.

- Failure: slice 2.4's parity can be marked done by flipping a value, without the bespoke editor.
- Fix: refuse book `generic` where the panel verb is not `generic` (or hold that set to a shrink-only baseline). Add a red control.
