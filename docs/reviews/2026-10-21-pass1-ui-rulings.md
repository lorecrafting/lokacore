## Proposed checks (developer slice)

- Log line: a test that a two-record receipt yields two log lines (UO).
- `words.ts` `REASON` covers every `ErrorCode` the GameView can advertise on an offer (`cooldown`, `over_load` once added): a test that each advertised code maps to a word, not a code.
- Room page: no `LogLines` after the Word block; Map page: no `LogLines` (a story or render test).
