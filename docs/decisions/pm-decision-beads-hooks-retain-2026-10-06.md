# PM decision: retain the opt-in Beads import hook — 2026-10-06

Under the [owner-approved Beads Rust pilot](owner-decision-beads-rust-pilot-2026-10-06.md), retain the repo-owned import hook only in the selected main integration checkout for the rest of Chapter 1. The [comparison](../evidence/2026-10-06-beads-hooks-pilot.md) has two actual source merges: C4 left JSONL unchanged, while D3's reviewed status commit changed it and the post-merge hook imported that newer file. Beads stayed healthy with 33/33 coverage, zero drift and current ready work. No manual recovery was needed after either observation.

The hook has not shown a measured speed gain; hook-only latency and Claude/Codex handoff time were not measured. Its observed value is keeping the selected local graph current when reviewed JSONL advances. It never closes issues, writes the roadmap, stages or pushes files. PM remains the single tracker writer, and source review/CI never depends on `br`. Keep other checkouts unselected and revisit this choice only if the hook produces drift, stale status or meaningful maintenance cost. Removing the local opt-in remains `git config --local --unset loka.beads.integrationRoot` in that checkout; retiring the tracked pilot requires a reviewed change.
