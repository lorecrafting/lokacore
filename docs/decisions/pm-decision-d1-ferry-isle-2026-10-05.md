# PM decision: D1 paid ferry, Sedge and safe isle return — 2026-10-05

Under the [autonomous mechanics delegation](owner-decision-autonomous-mechanics-2026-10-03.md), the PM adopts the [ferry mechanic](../system/mechanics.md#d1-paid-ferry-and-sedge-lesson-selected-contract), [composition](../system/protocol.md#d1-ferry-transport-composition), [chapter source declarations](../system/cartridge.md#d1-ferry-and-isle-declarations), [save recovery](../system/save.md#d1-ferry-and-lesson-recovery) and [Book flow](../system/book-ui.md#d1-ferry-and-sedge-details). The [source brief](https://github.com/lorecrafting/lokacore/blob/f8513671ea7dd84d681876b2e36850129a4b0564/docs/briefs/chapter-one/d1-ferry-isle-brief-2026-10-05.md) is ready for fresh independent planning review. This decision does not implement or approve source.

An unattended rope ferry charges 2p outbound to Sedge's declared balance, returns free, and waives outbound fare only for the actor's actual nonempty isle corpse. The player and a valid following Wren cross in one accepted action. The six-room route remains open for gear-free return from the current Chapel Nave death shrine; Isle Shrine is not a new respawn point. Sedge is available all hours in Isle Hut and immediately teaches swim for free through C1's acquired-skill owner, without S27 completion. D1 uses vacuous skill qualification because no water action or CON attribute is installed; D6 later re-pins its provisional CON threshold and owns actual underwater admission.

Published B8 [Maud's paid room, meal and drink services](pm-decision-b8-mauds-services-2026-10-05.md) provides exact conserved payment and a useful view/admission pattern. Its `use_service` command requires a present living NPC and its closed benefits cannot move an actor. D1 therefore adds the narrow transport command/offer for the first actual crossing, reusing B3 payment and PR #190 (Wren's escorted return to Elspeth) travel consequences. The ferry does not invent a remote NPC service, widen B8's benefit union, or call Move twice. The source brief freezes the proposed command and action keys; a developer must bring any incompatible protocol or save conflict back to PM before implementation.

Archived `00a-chapter-one-content.md` §§2/4/5/7/11 supplies the map and story intent. The [real-cast decision](owner-decision-real-chapter-cast-2026-10-05.md) excludes Bram from active play; the [no-wait decision](owner-decision-no-wait-opening-2026-10-05.md) removes a timetable/tide gate. The [Legend recovery decision](pm-decision-legend-mechanics-reconciliation-2026-10-04.md) requires an actual corpse route. Active B4 darkness, C1 skills and current chapel death custody govern where the archive differs. No token discount, herbalism training, S27 gating, new quest, water rule or native proof is adopted here.
