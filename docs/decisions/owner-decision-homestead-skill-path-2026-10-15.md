# Owner decision: in Homestead the skill path replaces NPC cooking and building — 2026-10-15

Written 2026-10-15 in Claude Code (PM). The owner's words are paraphrased.

Owner, 2026-10-15 (paraphrased): in Homestead the skill path replaces NPC cooking and building. A
paid NPC alternative reaches only a beginner tier; better results need the player's own crafting.
Skill trees in the style of Star Wars Galaxies are approved ("yes SWO skilltrees sounds good").

## Effect

1. Homestead cooking and building run through the player's skills, not through an NPC cook or a hired
   carpenter as the main route.
2. An NPC that cooks or builds for pay is a convenience: it produces beginner-tier results only.
   Anything above that tier needs the player's own crafting skill.
3. Skill trees, Star Wars Galaxies style, are the progression shape for those skills.

This overrules the PM ruling "cook NPC, not self-cooking" in the notes of `loka-kgd.108`.
