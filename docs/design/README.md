# Design Documents

Strategic game design documentation for Loka. These documents capture design philosophy, ideation, and future direction rather than technical implementation details.

## Documents

### [AI Resilience Strategy](./ai-resilience-strategy.md)

How Loka positions itself in an age of LLM automation:
- What can and cannot be automated
- Why prevention is futile
- Design patterns for coexistence
- The "Living School" vision
- Mentorship and emotional intelligence systems

### [Social Primitives](./social-primitives.md)

Foundational building blocks for social systems:
- Communication primitives (say, tell, channels)
- Expression primitives (emotes, moods, poses)
- Relationship primitives (friends, trust, follow)
- Group primitives (party, guild, channels)
- Witnessing and oath systems
- Implementation priority tiers

## Philosophy

Loka is designed as a **social-first** game where:

1. **Value comes from relationships**, not grinding
2. **Progress means growth**, not accumulation
3. **Content is co-created** by players
4. **Community is the game**, not just a feature
