# Prose in the Book: design rulings for loka-vduxr.53 (E5)

Decided, one pass, inside the [authoring editor plan](../decisions/owner-decision-authoring-editor-plan-2026-11-04.md) (promises 1, 2 and 5; "no modes") and the [GUI editor design](../rnd/gui-editor-design-2026-11-04.md) (ruling 13, section 11); the plan is not reopened. The routes are E1's ([author preview](../system/cartridge.md#author-preview)). The spec is [Author mode](../system/book-ui.md#author-mode-dev-only); this record holds the reasons.

Author mode is the `?dev=1` dev-cartridge page only; a release, test or e2e bundle never reaches it. Everything below is drawn over the Book from `mobile/app/author/`; no component in `mobile/app/book/` gains a prop, a state or a word (GUI design section 10: a menu inside `mobile/app/book/` is a finding). No new token and no new hex: every mark reuses `warning`, `action`, `dim`, `card`, `size.speechBar`, `size.focus` and `size.rule`. Chrome words live in `mobile/app/author/` (never `LABEL`, which ships).

## Rulings

| Question | Ruling | Why |
|---|---|---|
| What opens the field | A double-click on a line's words. A link or card inside the line keeps its click (the first click of a double-click plays it, as ruling 13 says a click plays); the field opens from the line's other words. The Book never delays a click to wait for a second one | The Book stays instant; delaying every click to detect a double-click would slow play for the author |
| Field look | The line itself becomes the field: its own type role at the current reading size, its own wrap and width, `fg` ink on `card` paper, the web focus ring (`size.focus` in `action`), caret `action`. Selection is the browser's own. It opens with the double-clicked word selected (the browser already did it) | "In the Book's own type": the owner writes where the player reads, and nothing reflows on open. `fg` on `card` is 9.51 or more in every palette |
| What the field holds | The source words of the line, unbound: `{actor}`-style slots as written, `~` as written. A speaker-joined line (`Nell says to you, "..."`) edits only the quoted words, its key's text | The route writes the source line; showing the bound sentence would write the binding into the source |
| Multi-line paragraph | A paragraph is one source line (a JSON string, a `* ` scene line, a `.cut` step), so it is one soft-wrapped field that grows with its words. It never holds a break: Enter saves, Shift-Enter does nothing, a pasted newline or tab becomes one space | `/edit` refuses a newline or tab; one field type for every line |
| Save | Enter, or leaving the field (blur). Unchanged words write nothing. An empty field does not save: it says `Empty. Write ~ to leave it unwritten.` and stays open | The plan's commit points (Enter, blur), not per keystroke and no second shortcut. Empty would silently delete words |
| Cancel | Esc restores the words and closes the field; focus returns to the line | Standard; the keyboard path needs a return point |
| Field caption | Under the open field, in `type.label` `dim`: `<file>:<line>  Enter saves · Esc cancels` | Names what is being written; dim on card holds 4.91 or more |
| While the compile confirms | The words show at once (the overlay) and the line is drawn as any line: nothing marks it. The console shows `compiling` as it does for a card write | A normal confirm takes about a second; a mark that flickers on every save is noise |
| Unconfirmed (compile refused) | The line keeps the owner's words with a wavy underline in `warning` (dotted is the fixture link), static; its accessible name adds `unconfirmed`. The console badge reads `The Book shows unconfirmed words (N)`, listing each line's `file:line` and the refusal. A later good compile clears the marks | Not colour alone: the wavy line is the cue. Static, so reduced motion needs nothing. `warning` holds 4.75 or more on paper and card |
| Put it back | Cmd-Z (Ctrl-Z) outside any text field puts back the owner's last prose edit made from this page (`/undo` with the id `/edit` answered). Each press walks one further back through this page's edits; there is no redo. Inside the field Cmd-Z is the field's own text undo. The line shows the old words at once. The console feed row reads `put back <file>:<line>`; nothing left reads `Nothing of yours to put back.` The feed's own put-it-back control (plan) stays the mouse path | The newest journal entry may be an outside or card write; the owner's shortcut must undo what the owner just wrote. No redo is the design's rule (5.4) |
| Put back refused | `/undo` 409: the console says `<file> changed since; not put back.` with Open source | The journal's rule: never overwrite a change made after |
| `~` mark | In author mode a line whose words trim to `~` gets a margin bar: `size.speechBar` wide, `warning`, in the page's left margin beside the line's full height; the line itself is unchanged. Its accessible name adds `still to write` | A manuscript change bar: it stands out at a glance and moves nothing. The `~` glyph plus the bar is not colour alone; the bar is 5.12:1 or more on paper (3:1 is the bar for a mark) |
| Jump keys | `]` next, `[` previous, over the `~` lines this page shows, in page order, wrapping. The landed line scrolls into view, takes the focus ring and the bar turns `action`. `}` and `{` do the same over every editable line on the page. Enter on a landed line opens its field | A double-click has no key: this is the keyboard path to every line, and the `~` walk is promise 5 |
| Counts | The console header: `~ 2 of 5 here · 41 in cartridge`; "here" is the `~` lines the page shows, the cartridge count is `todo.ts`'s. With none here: `~ 0 here · 41 in cartridge` and the keys do nothing | Many `~` lines (dialogue, `.cut` steps) never draw on the room page; the Book does not show counts, so the page stays the game's |
| Past this page | The jump does not leave the page. A `~` elsewhere is reached from the console's Still to write list (open source, or select once the hierarchy has it) | `go_to_room` is a recorded step that would enter the place path, and it is refused in many states (engaged, in a scene, at a choice); a dialogue or `.cut` line needs a conversation state no jump can make |
| Keys never fire | while focus is in a text field (the say field included) or with Cmd, Ctrl or Alt held (Cmd-Z excepted). The keys work with focus in the Book frame or the panel | The say field types `[`; a relay from the frame is the design's section 11 note |
| 409 on save | The field stays open with the owner's draft. Under it, in `warning`: `Changed on disk since you opened it.` and their line's words. Two controls: Keep mine (writes the draft against their line, found again in the current bytes) and Take theirs (drops the draft and shows theirs). If their line cannot be found exactly once, only Open source shows. The same notice opens at once when a pushed `changed` names the field's file and its line differs | `was` is the line itself, so a shifted line is a 409 too. Keep mine after seeing theirs is the design's "last writer must have seen the latest bytes" (ruling 4). Reload and Take theirs are one action here: the Book already shows theirs through the overlay |
| Hold | In the panel header, not the Book: a Hold toggle, pressed while held, and a badge `Held · N waiting` in the chrome's `warning` ([editor chrome](editor-chrome-rulings.md#3-semantic-colours); N the parked changes), whoever set it. Leaving the page (`pagehide`) releases a Hold this page set | The Book stays a snapshot; the Hold is about the frame, so the frame's chrome says it |
| Lines with no field | A double-click on a line that is not words (a choice label, an engine line, a line the route refuses) opens no field. A note under the line, `type.label` `dim`, until the next click or key, read politely: a choice label `A choice label is its key. Alt-click opens the scene.`; an engine line `The engine writes this line.`; any other refusal `Not a line of words. Alt-click opens its source.` | The reason and the way to the source, in one line; the `---` of a `.cut` and a key line never draw in the Book, so the route's refusal is their only path |
| Reduced motion | Nothing here moves: the field, the marks, the notes and the jump appear and go as cuts; the scroll to a landed line is instant under reduced motion | No new motion token |
| Contrast | Every mark uses a text role already at 4.5:1 or more in all four palettes, on paper and on card; under the spirit and reverie layers the [treatment numbers](book-treatments-rulings.md#contrast-numbers-wcag-2-every-text-role) hold | Worst case light `warning` on `card` 4.75 |

## Known limits

- Hold is one flag for the whole watcher: a page that set it releases it on leaving, even if another open page wants it held; a Hold whose page died without `pagehide` stays until toggled. Accepted (one author, one page).
- A line is found by its shown words (`seen` in `panel.tsx`); two keys with identical words resolve to one. Existing behaviour, not widened.

## Proposed check

None new: no raw colour or size is introduced. The `mobile-book-*` ast-grep rules run on this slice; any author code under `mobile/app/book/` beyond the existing `worded.note` hook is a finding.
