# Loka Brainstorming Framework

> **Purpose:** Offline thinking tool for RPG game design and lore creation
> **No experience required** - just questions to spark ideas

---

## Development Time Estimation Rule

**All development time estimates should be in LLM time (Claude Opus 4.5), NOT human coding time.**

| LLM Time | Human Equivalent | Task Type |
|----------|------------------|-----------|
| 1-2 min | 15-30 min | Add a button, simple edit |
| 5-10 min | 1-2 hours | Bug fix with investigation |
| 15-30 min | 4-8 hours | Feature implementation |
| 1-2 hours | 1-2 days | Complex multi-file feature |

**Why:** LLM reads/writes code instantly, doesn't context-switch, parallelizes investigation. Human estimates are misleading when LLM is doing the work.

## Part 1: What Makes Games Feel "WOW"

Before diving into mechanics and lore, think about what makes games memorable:

### The Feeling Checklist
Ask yourself: When I think of my favorite games, what do I remember?

- [ ] **A moment** - A specific scene, reveal, or choice that stuck with me
- [ ] **A character** - Someone I cared about (or loved to hate)
- [ ] **A place** - A location that felt real, that I wanted to explore
- [ ] **A system** - A mechanic that was fun to master or experiment with
- [ ] **A community** - Other players, shared experiences, inside jokes
- [ ] **A feeling** - Cozy? Epic? Mysterious? Bittersweet?

**Exercise:** List 3-5 games you love. For each, write ONE sentence about what made it special. Look for patterns.

```
Game: _______________
What made it special: _______________

Game: _______________
What made it special: _______________

Game: _______________
What made it special: _______________
```

### The "Polish" Question
"Polish" isn't about graphics - it's about **intentionality**. Every element should feel like it belongs.

Signs of polish:
- Small details that reward observation
- Consistency (if magic works X way here, it works X way everywhere)
- No "placeholder" feeling - everything has a reason
- Surprises that feel earned, not random

**Question to return to:** "Does this element EARN its place in the game?"

## Part 4: Tying Lore + Mechanics Together

This is where magic happens. Every mechanic should have a lore reason. Every lore element should have mechanical expression.

### The Integration Matrix

| Mechanic | Lore Justification | Does it FEEL right? |
|----------|-------------------|---------------------|
| Gate travel | Ancient tech + player effort | |
| Spark companion | Fragment of gate network | |
| [Your mechanic] | [Your justification] | |

### The Reverse Check
For every lore element, ask: "How does the player EXPERIENCE this?"

```
Lore: The collapse happened
Experience: Refugees tell stories, ruins exist, news arrives

Lore: Planets have different cultures
Experience: Different aesthetics, dialogue, values in NPCs

Lore: _______________
Experience: _______________

Lore: _______________

```

### The "Show Don't Tell" Test
Can you communicate this WITHOUT exposition?

```
Instead of: NPC says "The old world collapsed"
Show: Player finds a child's drawing of burning cities

Instead of: Tutorial explains gate mechanics
Show: Player watches an NPC fail to use an unstable gate

Your turn:
```

## Part 8: Questions to Sleep On

These don't need immediate answers. Let them percolate.

1. What's the ONE thing you want players to FEEL?
2. If a player describes your game to a friend in one sentence, what should they say?
3. What's the equivalent of "the cake is a lie" - a moment that recontextualizes everything?
4. What would make a player come BACK after a break?
5. What story do you want players to tell each other?

## Quick Reference: What We've Decided So Far

### Setting
- Core worlds collapsing (wars, chaos, environmental collapse)
- Frontier worlds reopened via ancient gates
- Players are refugees who chose to build something new
- Tone: "Clear but distant" - collapse is real but focus is on the future

### Player Origin
- Different arrival per planet (seedship, consciousness transfer, cryo-crash)
- Memory: Core motivation only, personal details foggy
- Spark bonds during awakening

### Gates
- Ancient technology + player effort to stabilize
- Travel gated by planetary development
- Resource cost + progression requirements

### Cultural Divergence
- "Cultural arks" - intentional colonization by value-aligned groups
- Environment reinforced traits over generations

### Starter World
- Frontier town vibe
- Community-focused, hopeful, everyone pitching in
- Shadow: conformity pressure, suspicion of those who leave

### NOT Decided
- Planet names
- Other two planets' identities
- Timeline specifics
- Specific mechanics
- Faction details
