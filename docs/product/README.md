## Guiding Principles

1. **Player-first** - Monetization should never compromise gameplay
2. **Transparency** - No hidden costs or manipulative patterns
3. **Sustainability** - Build for long-term health, not short-term extraction
4. **Alignment** - Revenue model should reinforce game values
