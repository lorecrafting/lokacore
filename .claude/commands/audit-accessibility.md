# Accessibility Audit

Ensure the game is playable by users with various abilities.

> **Timeout Budget**: 8 minutes

## Areas to Audit

### A. Visual Accessibility
- Color contrast ratios (WCAG AA/AAA)
- Color-blind friendly design
- Font size and scaling
- Focus indicators visibility
- High contrast mode support

### B. Motor Accessibility
- Keyboard-only navigation
- Click target sizes
- Drag-and-drop alternatives
- Time-sensitive action alternatives
- One-hand playability

### C. Cognitive Accessibility
- Reading level of text
- Information chunking
- Consistent navigation patterns
- Clear error recovery paths
- Progress saving frequency

### D. Screen Reader Support
- ARIA labels on interactive elements
- Semantic HTML structure
- Live region announcements
- Form field labeling
- Image alt text (if any)

### E. Game-Specific
- Combat pace adjustability
- Text speed options
- Quest log clarity
- Map/navigation alternatives
- Audio descriptions (future)

### F. Technical
- Reduced motion support
- Prefers-color-scheme support
- Font loading fallbacks
- Responsive breakpoints
- Touch vs mouse handling

## Deliverables

> **Report only**: Do not create beads automatically. Present findings and await user direction.

1. WCAG violations by priority (bead-ready format)
2. Quick wins for accessibility
3. Larger accessibility initiatives
4. Note if docs/ui/accessibility.md should be created
