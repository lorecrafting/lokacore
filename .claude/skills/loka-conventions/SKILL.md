# Loka Code Conventions Skill

**Auto-applies when**: Writing or modifying Elixir code in the Loka codebase

## Purpose

Ensures all code follows Loka conventions for:
- Module organization
- Naming patterns
- Documentation standards
- Error handling
- Architecture boundaries

## When Claude Uses This

This skill activates automatically when you:
- Write new modules or functions
- Refactor existing code
- Review code changes
- Create new features

Claude will reference the guidelines in this skill to ensure consistency.

## Key Conventions

See supporting files:
- `NAMING.md` - Naming conventions
- `PATTERNS.md` - Common patterns
- `ANTIPATTERNS.md` - Things to avoid
- `ARCHITECTURE.md` - Layer boundaries
