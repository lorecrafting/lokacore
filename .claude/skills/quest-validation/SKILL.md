# Quest Validation Skill

**Auto-applies when**: Editing quest YAML files

## Purpose

Ensures quest definitions are valid and follow Loka quest structure.

## When Claude Uses This

Activates when you:
- Create new quest files
- Edit quest definitions
- Modify objectives
- Update rewards

## Validation

- Required fields present
- Objective types valid
- Target IDs exist
- Reward structure correct
- Giver NPC exists
- Quest chain integrity

See `STRUCTURE.md` for quest YAML format.
