# Narrative Audit

Review story consistency, lore accuracy, and writing quality.

> **Timeout Budget**: 8 minutes

## Areas to Audit

### A. Lore Consistency
- Timeline consistency across NPCs
- Character backstory alignment
- Location history accuracy
- Event references matching
- Faction relationship consistency

### B. Character Voice
- NPC personality consistency
- Dialogue tone matching character
- Speech pattern uniqueness
- Mood/personality reflected in dialogue
- Character growth through dialogue

### C. World Building
- Room descriptions atmosphere
- Environmental storytelling
- Cultural consistency (Tibetan Buddhist themes)
- Geographic logic in descriptions
- Weather/time references accuracy

### D. Quest Narratives
- Quest descriptions matching objectives
- Story progression logic
- Character motivations clarity
- Reward narrative justification
- Resolution satisfaction

### E. Writing Quality
- Typos and grammar errors
- Awkward phrasing
- Repetitive language
- Purple prose vs clarity balance
- Dialogue naturalness

### F. Thematic Coherence
- Three Poisons theme integration
- Buddhist concepts accuracy
- Moral complexity in choices
- Symbolism consistency
- Tone consistency across content

## Deliverables

> **Report only**: Do not create beads automatically. Present findings and await user direction.

1. Inconsistencies with specific locations (bead-ready format)
2. Writing quality issues with examples
3. Lore gaps that need filling
4. Note if docs/design/lore-bible.md should be created
